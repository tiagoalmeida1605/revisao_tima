# Funções

## Introdução

Uma função é uma relação entre dois conjuntos em que cada valor de entrada corresponde a um único valor de saída. Em Matemática, esse conceito aparece em problemas de proporcionalidade, gráficos, fórmulas e modelos de crescimento.

## Conceitos fundamentais

- Domínio: conjunto dos valores de entrada.
- Contradomínio: conjunto em que as saídas podem ser encontradas.
- Imagem: conjunto com os valores realmente obtidos.
- Gráfico: representação visual da função.

## Como identificar uma função

Para que uma relação seja função, cada entrada deve produzir apenas uma saída. Em uma tabela, dois valores iguais no eixo x não podem corresponder a resultados diferentes.

## Exemplos resolvidos

Se a função for `f(x) = 2x + 3`, então:

- `f(1) = 2·1 + 3 = 5`
- `f(2) = 2·2 + 3 = 7`
- `f(3) = 2·3 + 3 = 9`

O gráfico dessa função é uma reta crescente.

## Erros comuns

- Confundir domínio com imagem.
- Achar que toda equação representa uma função.
- Ignorar a ordem dos pares em um gráfico.

## O que revisar para a avaliação

- Leitura de gráficos.
- Identificação de domínio e imagem.
- Cálculo de imagem de uma função.
- Interpretação da taxa de variação.

> Se a função cresce e a taxa de variação é constante, ela é linear.
